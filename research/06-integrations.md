# 06 — Integrations

## 1. WordPress Plugin — "Push Notifications by LaraPush"
- **WordPress.org slug:** `push-notifications-by-larapush`; free; latest ~1.0.10.
- **Installs:** 5,000+ active.
- **Requirements:** WP 4.7+ (tested to 6.8.7), PHP 7.0+.
- **Features:** one-click push from WP dashboard; auto "Push on Publish" (Pro plan — plugin setting checkbox, optional delay); Web Stories support; AMP-validated code injection; iOS PWA support; Premium compatibility; "who can send notifications" control; masked password field; validate/verify flow.
- **Setup:** install → enter panel credentials (host/API) → LaraPush > Settings.

## 2. Code Integration — any website (the core integration path)
From official "Manual Code Integration" doc, full flow:
1. **Domain type** selection: WordPress / Website (custom) / iOS (Apple web) / **AMP** / **Blogger** → loads per-platform config page.
2. **Customize the prompt**: 4 types — **Custom** (branded), **Custom with Backdrop**, **Default/Native**, **Full-screen**.
3. **Advanced settings** for the prompt:
   - **Enable (bottom) Bell** + bell location + unlock custom unsubscribe options
   - **Prompt Location on mobile**: left / right / center
   - **Custom Prompt show/hide on desktop & mobile** independently
   - **Prompt delay** — how long after page load to show
   - **Prompt re-appearance** — after user denies, when to show again
   - Real-time preview panel on right before save.
4. **Copy script** → paste in `<head>` of site → click **Verify** (checks correctness).
5. **Download 2 files** (firebase-messaging-sw.js + manifest etc.) → upload to site public root (public_html for WP).
6. Clear CDN/cache (Cloudflare/WP cache) caveat. Optionally Auto Code Integration (general setting) auto-injects into WP.

## 3. Blogger
- Blogger Code Integration page: config heading, subheading, logo URL, Allow button text, Deny button text, popup preview.
- Demo snippet pasted **just before `</html>`** in Blogger theme (not `<head>`), then confirm-checks checkbox "I confirm that popup is visible in my website" → click Save → live.
- Reaches Blogger, AMP compatibility (Discover eligibility) kept.

## 4. iOS — PWA (new / existing)
- **New PWA mode:** fields — **PWA App Name**, **Start URL**, **Icon URL (512x512)** (add icon512.png), **prompt text** (3-step add-to-home-screen instructions), **reappear time** (seconds). Right-side real-time iOS preview. Download ZIP with `firebase-messaging-sw.js` + `manifest.json` + `icon512.png` → upload to public root. Confirm checkbox "popup visible".
- **Existing PWA mode:** provide **service worker file URL** (e.g. /firebase-messaging-sw.js), prompt instructions, reappear time; paste `<head>` snippet; update existing service worker with push config from dashboard; confirm.
- iOS 16.4+ Safari only; auto-detects compatible devices.

## 5. YouTube
- **YouTube Links** (Premium): short links for video descriptions / pinned comments → subscription prompt.
- **YouTube Push** (Premium): auto-campaign right after upload; per-channel list (LP link, desktop/mobile subs, status, active/pause/delete).
- Console under **"Collect"** menu.

## 6. Google Drive Backup (Premium)
- Manual or scheduled backups; "Send To Drive" upload; service-account JSON authentication; license verify.

## 7. REST API (developers) — DEEP
- Enable: **System Settings → API** ("Turn on API").
- Free unlimited calls. Postman public collection "LaraPush API" (8 items, published Sept 2022): send push (all), send push (segment), send push (selected ids), list campaigns, home stats. Endpoint host = your panel URL (Postman variable `Host`). Auth: Bearer/API token generated by panel.
